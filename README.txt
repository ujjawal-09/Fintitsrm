FINDIT - Intelligent Campus Lost & Found System
Raj Singh, Kshitij Purbey, Ujjawal | B.Tech CSE (Data Science - B), SRM Institute of Science and Technology

DESKTOP APP (Java)
1. Install free Java 17 or 21 from https://adoptium.net
2. Double-click run.bat (Windows) or run.sh (Mac/Linux). FindIt.vbs also works on Windows with no black window.
   Or run:  java -jar FindIt.jar
3. Register yourself: phone number -> OTP -> username & password -> your details. Then login.
   (OTP is a demo and is shown in a pop-up, as a desktop app cannot send real SMS.)

WEBSITE VERSION
Double-click FindIt_Website.html. It opens in any browser, no install needed.

Source code: FindIt.java
Data is saved in findit_data.txt and findit_users.txt next to the app.
